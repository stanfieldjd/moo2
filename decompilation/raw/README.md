# Raw Decompiler Output

Store untouched, tool-generated analysis artifacts here only when their distribution is lawful.

For every import, record:

- source executable SHA-256;
- tool and exact version;
- loader and processor settings;
- analysis options;
- generation command or procedure;
- output-file hashes;
- generation date.

Never hand-edit raw output. Place annotations and renamed interpretations in `../annotated/`.
