# Analysis Tools

This directory contains reproducible utilities for lawful local analysis, extraction, conversion, validation, and report generation.

Tools must:

- require the user to supply their own original files locally;
- verify expected hashes or record unknown hashes;
- avoid embedding proprietary bytes;
- produce deterministic output where practical;
- document inputs, outputs, versions, and failure modes;
- fail clearly rather than silently substituting fallback behavior.
