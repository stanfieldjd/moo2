# Authority and Evidence

## Authority order

1. Directly reproduced official v1.31 behavior.
2. Official MicroProse documentation and release material.
3. Verified binary analysis of official v1.31.
4. Later patch notes and reverse engineering used to diagnose defects.
5. Corroborated community observations.
6. Unverified reports and hypotheses.

A higher-ranked source can still be incomplete or wrong. Record conflicts instead of silently selecting convenient evidence.

## Required evidence record

Every material claim must identify:

- proposition;
- source and version;
- file hash or stable citation when applicable;
- reproduction steps;
- observed result;
- confidence: low, medium, or high;
- status: hypothesis, reproduced, corroborated, or verified;
- conflicting evidence;
- downstream code and tests.
