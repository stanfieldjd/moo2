# Original MOO2 v1.31 research planet-special provenance

A remaining source-reachability question from the original research production breakdown/numeric dependency was whether planet BYTE `+0x0F` values **10** and **11** are original generated state values or merely artificial test inputs.

The official local v1.31 executable and complete original function digests establish an affirmative *value-generation* answer. The original new-game call route `Init_New_Game_ -> Generate_Home_Worlds_` contains direct calls to `Modify_Home_Worlds_` and `Generate_Orion_`. The home-world modification original code writes **10** to planet BYTE `+0x0F` on a positive player BYTE `+0x8AF` condition, with a parallel original star-record change. Orion-generation code writes **11** to the same original planet field, although it also explicitly marks the planet WORD `+0x00` initially `0xFFFF` (unowned). A third original named helper `Enforce_Artifacts_Special_` independently writes **10**, but no caller for that helper was proved in the direct named callgraph.

The original `Colony_Research_Per_Scientist_` reads that exact planet field using the same original DATA `_planet` global at `0x1B0D4` and original 17-byte record stride; it assigns **+2** for 10 and **+5** for 11. On its non-null breakdown-output path it also adds those corresponding amounts to DWORD `+0x226`, which is the previously traced breakdown-to-numeric cross-function alias.

All six original machine-code named bodies, 28 exact opcode source checkpoints, three direct generation CALL edges and 13 bounded fixtures are checked by `tools/audit_research_planet_special_origin_v131.py`; reproducible machine-readable evidence: `decompilation/reports/research_planet_special_origin_v131_2026-10-16.json`. Detailed disassembly-offset interpretations and all confidence limits: `decompilation/annotated/research_planet_special_origin_v131.md`.

**The limit is material:** assigning a planet code during galaxy generation is not proof that a populated colony with that code can satisfy every other synthetic research-production predicate. Orion begins unowned.
