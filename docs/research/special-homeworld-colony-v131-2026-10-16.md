# Source provenance: an artifact-code home world is constructed with a colony and research workers

The original v1.31 DOS game code now supports a stronger conditional state chain than merely assigning planet-special code 10. In original Modify_Home_Worlds_ CODE 0x6C635, when player BYTE +0x8AF is nonzero, the selected home-world planet gets BYTE +0x0F set to 10. Later in that **same function**, CODE 0x6C697 passes the **same selected planet index** to original Init_Homeworld_Colony_ at CODE 0x6C6A3.

The original homeworld wrapper calls Init_Homeworld_Colony2_, which calls Init_Colony_. Original Init_Colony_ writes the new colony slot to planet WORD +0x00, selected planet index into colony WORD +0x02, and home-world player owner into colony BYTE +0x00. Thus the code-10 planet can be paired with a legitimate newly initialized colony in the original new-game code path.

Source population initialization is likewise concrete: when the original settings BYTE 0x21CB5 differs from 2, the colony population BYTE +0x0A is set to 8. The entry loop assigns each citizen a packed original owner tag (low nibble), a job selector (bits 7–8), and the active worker participation flag (bit 9). Depending on original planet and player conditions, the job assignment is either i%3 (food/industry/research cycle) or (i%2+1)&3 (industry/research cycle). Both branches contain research workers for 3 or more entries; a population of 8 is therefore sufficient.

The direct calls, original data-field linkage, machine-code anchors and exactly bounded job-fixture arithmetic are reproduced by tools/audit_special_homeworld_colony_v131.py, with report decompilation/reports/special_homeworld_colony_v131_2026-10-16.json and annotation decompilation/annotated/special_homeworld_colony_v131.md. This audit SHA-256 authenticates seven original named v1.31 functions; it decodes 1,030 instructions within stated scopes, checks 61 original opcode anchors and 420 controlled assertions. It explicitly excludes unsupported whole-function instruction-coverage claims for the longer Init_New_Game_ and Init_Colony_ decoder-hole regions.

This closes the source gap between **planet special assignment and home-world colony population**. It does not yet prove that the particular government, race-option legality, production setting and other fixture assumptions used by the earlier research display/no-display discrepancy are all jointly reachable in a normal game save. No DOS runtime differential comparison or changes to game rules are claimed.
