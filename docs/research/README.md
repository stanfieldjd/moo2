# Reverse-Engineering Research

Use one Markdown file per subsystem or investigation.

Each record must contain:

- question;
- exact target version;
- evidence;
- tools and versions;
- commands or procedure;
- addresses and byte ranges where applicable;
- observations;
- interpretation;
- alternatives considered;
- confidence;
- verification method;
- affected tests and implementation;
- unresolved questions.

Do not edit raw decompiler output here. Reference it by stable path and hash.
