# Symbol Registry

Maintain machine-readable symbol tables alongside explanatory notes.

Minimum symbol fields:

- executable SHA-256;
- address;
- segment/section;
- kind;
- proposed name;
- original/generated name;
- calling convention or data type;
- size;
- evidence reference;
- confidence;
- status;
- notes.

Never reuse an address mapping across executable hashes without verification.
